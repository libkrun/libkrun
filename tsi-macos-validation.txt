Coverage and implementation changes
-----------------------------------
* Automatic INET hijacking and explicit AF_TSI/AF_TSI6, both IPv4 and IPv6,
  with no guest eth0. Static Rust and dynamic C API loading both exercised.
* TCP outgoing/incoming, nonblocking connect, refusal and SO_ERROR clearing,
  pending-connect errors and close, independent TCP bulk and UDP progress,
  256 KiB transfers, half-close, local/peer names, NODELAY replay, and lifecycle.
* Mapped/unmapped host publication conflicts, guest-local default fallback,
  absence of automatic later publication, close/recreate default retry,
  strict same-bound-socket retry and externally reachable successful listeners.
* UDP connected/unconnected/reconnect, AF_UNSPEC disconnect, peer filtering,
  bound source-port preservation, incoming traffic before guest send, empty
  and larger packets, peek, full/truncated receive counts, options/names,
  oversize error and repeated replacement. IPv4/IPv6 destination/interface
  metadata checked on incoming wildcard traffic, including a second host IPv4.
* Real curl HTTP/HTTPS, wget, UDP/TCP dig, large DNS and fallback, dnsmasq,
  Python HTTP server, OpenSSL DTLS, and unprivileged iputils ping in both families.
* Portable control-wire framing/validation, unsupported protocols/families,
  duplicate create, options/names, 32 create/bind/query/release cycles,
  malformed datagram rejection and translated Linux pending-error clearing.
* Instrumented GETNAME and SO_ERROR/GETOPT: malformed responses, wrong IDs
  and sources, duplicates, dropped replies and bounded deadlines, recovery,
  64 stale replacement cycles per operation, deferred ordinary signals,
  fatal cancellation, and proxy cleanup. Uncertain CREATE/SETOPT/LISTEN
  poisoning and malformed LISTEN policy flags also exercised under both policies.
* Darwin connected sends to their existing peer now omit the native destination
  argument, avoiding EISCONN. Native UDP receive no longer supplies MSG_TRUNC,
  which Darwin otherwise echoes on complete packets. Wrong-family datagram
  errors are translated from Darwin EAFNOSUPPORT to Linux errno 97.
* Darwin ICMP uses native datagram sockets. Each proxy reserves a distinct
  host echo identifier through an idle loopback UDP port, rewrites/restores
  IDs/checksums and filters by identifier, sequence, peer and payload hash.
  IPv4 headers are stripped; destination/interface and TTL/hop-limit metadata
  are normalized. Foreign replies and IPv6 requests are filtered. Transient
  receive errors are excluded from pending SO_ERROR, matching UDP handling.
* Native ICMP units verify colliding guest IDs, distinct host IDs, payloads,
  odd/even checksums, IPv6 checksum adjustment, metadata and reservation release.
  Real ping checks normal, -C and -e4242 modes, guest-local routing, plus two
  simultaneous same-ID clients with different patterns in each guest. Two VMM
  processes were also launched together: trace timestamps overlap for both
  families and their reserved host identifiers are disjoint. results.json
  records timestamps and identifier sets. The earlier unsynchronized
  cross-vm-{1,2} runs are not used as evidence of concurrent execution.
* Native C API firmware probes reject ABI 5, ABI 7 and absent version getters
  before kernel loading, with explicit ABI-6 diagnostics.

Limits and exclusions
---------------------
* Four existing curl parallel delayed/timeout fixtures (IPv4/IPv6) require
  Linux accept-queue behavior and skip on Darwin. Independent pending-connect
  TCP/UDP progress is covered by the new portable socket contract instead.
* Host AF_UNIX TSI is unsupported on macOS and its rejection is verified.
* Connected UDP sendto to a different explicit peer is not adapted; applications
  must disconnect/reconnect to change peers. Original lengths of native-host
  truncated UDP receives retain Darwin's copied-length limitation.
* ICMP covers unicast echo. Raw sockets, other ICMP types, error queues,
  outgoing TTL/hop-limit controls and scoped IPv6 targets were not implemented.
  Matching retains one request per 16-bit sequence, replacing it on reuse;
  each ICMP proxy consumes an extra host loopback UDP descriptor/port.
* General UDP receive TTL metadata remains Linux-specific; macOS ICMP reply
  TTL/hop-limit metadata is covered. No universal native-socket parity claim.
* The existing host ULA did not answer even the native ICMP probe. IPv6 tests
  use host ::1 while temporarily removing guest ::1, then restore it for
  guest-local checks. Only disposable guest network configuration is changed.
* Linux host runtime regressions and the original 668 functional/67 fault
  selftests were not rerun. FreeBSD, Windows, GPU and non-TSI device integration
  are outside this validation. Existing Linux sendto behavior was preserved.
